神秘小工具

真冬绘名桌宠 [ 桌宠 ]

一个包含真冬和绘名的桌宠。有番茄钟、点击互动、随机对话功能。使用Godot开发。点击进入详情页可查看安装指引，并跳转 itch.io 下载 Windows / Mac 版本。
海希海桌宠 [ 桌宠 ]

一个包含海铃和立希的桌宠。使用Electron开发，主要就是计数功能。点击进入详情页可查看安装指引，并跳转 itch.io 下载 Windows / Mac 版本。
Pixiv Contextual Translator [ 浏览器插件 ]

用于 Pixiv 的情境翻译插件，主要是我自己使用于阅读日语同人文。有自建词库功能。点击进入详情页可直接下载 ZIP，并查看安装教程（网页插件版本和 Android 插件版本）。需要使用你自己的 API Key，嗯有点烧钱。
海铃立希名字汉字测试 [ 小测试 ]

本来是给cp32pre的无料领取写的玩意儿结果我摊位没了。但是很好玩我还弄了家产的表情包来显示正确与否。点击进入详情页可直接下载 ZIP，并查看本地运行教程。可以自己改题目。
