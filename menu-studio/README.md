# 摊位菜单生成器（静态版）

这是一个无需服务器的菜单制作工具。直接双击 `index.html` 即可使用，也可以把整个文件夹上传到 GitHub Pages。

## 功能

- 自定义摊位资料、二维码、分类、制品、作者、价格、角标和跳转链接
- 上传摊位头图与制品图片，并调整图片焦点
- 五项自由配色和四套快捷配色
- 每个分类内采用电脑四列、平板三列、手机两列的图片网格，并在本机自动保存草稿
- 紧凑双色版头、淡方格背景和无边框平面商品模块
- 导出可点击链接的独立电子菜单 HTML
- 导出随内容自动增长的 PNG 长图、打印或存为 PDF
- JSON 草稿备份与恢复

## 使用

1. 双击 `index.html`，在左侧编辑内容。
2. 图片会嵌入菜单文件中；为避免浏览器存储空间不足，建议单张图片不超过 6MB。
3. 点击“导出电子菜单”，会下载一个独立 HTML 文件，可直接分享或部署。
4. 点击“长图 PNG”下载适合社交平台发布的整张菜单。
5. 点击“打印 / 存为 PDF”，在浏览器打印窗口选择“另存为 PDF”。

## 部署到 GitHub Pages

把此文件夹内的文件放入仓库，进入仓库 Settings → Pages，选择分支后保存。稍等片刻即可获得公开网址。所有功能都在浏览器本地运行，不会上传你的图片或草稿。
