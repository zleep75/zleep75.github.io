Pixiv Contextual Translator

这是一个用于浏览器的 Tampermonkey（油猴）脚本，专为阅读 Pixiv 同人小说设计。它通过调用大语言模型（LLM）API，结合上下文对段落进行就地翻译，有效解决传统机器翻译中因日语主语省略导致的视角混乱问题。

本项目包含 Desktop 与 Mobile 两个版本，分别针对电脑端和移动端进行了交互优化。你可以直接从本站下载 ZIP 后按下方文档安装。

下载压缩包（ZIP）

核心功能

  • 上下文感知翻译：自动抓取目标段落及其前后各两段内容作为上下文，利用大模型精确推断动作主体，保证连贯的人物视角。
  • 可视化专有词库：内置图形化词库管理器，支持“日文-中文”键值对的增删改查，词库数据保存在本地并自动注入提示词。
  • 支持重新翻译：点击已生成翻译结果的段落，可清空旧数据并重新触发 API 请求。
  • 无侵入式就地展示：翻译结果直接插入原文下方，不使用侧边栏或独立悬浮窗。

    • 注意：需要使用你自己的 API Key，调用模型会产生实际费用，请按需配置。

版本说明

  • Desktop 版（desktop.user.js）：适用电脑端浏览器（Chrome、Edge 等）；页面极简，不额外注入 UI，设置入口在浏览器右上角 Tampermonkey 菜单。
  • Mobile 版（mobile.user.js）：适用移动端浏览器（如 Android 的 Kiwi Browser）；网页右下角注入半透明悬浮齿轮（⚙️）按钮，可一键呼出管理面板，面板触控尺寸已放大优化。

安装指南

  1. 准备环境
    • 电脑端：在浏览器扩展商店安装 Tampermonkey。
    • 手机端：安装支持扩展的 Kiwi Browser，并在其扩展商店中安装 Tampermonkey。
  2. 安装脚本
    • 下载 ZIP 后完整解压到本地目录。
    • 在 Tampermonkey 中点击“添加新脚本”。
    • 清空默认内容，将对应脚本代码（desktop.user.js 或 mobile.user.js）完整粘贴进去。
    • 保存并启用脚本。

使用说明

  1. 配置 API Key
    • 打开任意 Pixiv 小说正文页面（URL 规则：*://www.pixiv.net/novel/*）。
    • 首次点击页面上的任意日文段落时，系统会自动弹窗请求输入 API Key（默认调用 OpenAI API 格式）。
    • Desktop 版修改路径：Tampermonkey 扩展图标 → 设置 API Key。
    • Mobile 版修改路径：右下角悬浮齿轮按钮 → 面板顶部“🔑 API Key”。
  2. 执行翻译
    • 将鼠标或手指停留在日文段落上，点击即可触发翻译。
    • 原文下方会显示“正在翻译中...”，请求完成后自动替换为中文。
  3. 管理词库
    • Desktop 版：Tampermonkey 扩展图标 → 管理专有词库。
    • Mobile 版：点击页面右下角悬浮齿轮按钮。
    • 在可视化面板中添加日文原文与中文翻译，保存后可立即生效。

高级配置（开发者选项）

脚本默认使用 OpenAI 的 https://api.openai.com/v1/chat/completions 接口和 gpt-3.5-turbo 模型。若需改用其他兼容 OpenAI 格式的 API（如 DeepSeek、Claude 代理等），可在脚本 CONFIG 对象中手动修改：

const CONFIG = {
  apiEndpoint: GM_getValue('api_endpoint', 'https://api.your-custom-endpoint.com/v1/chat/completions'),
  model: GM_getValue('model', 'your-preferred-model'),
  // ... 其他配置
};

技术栈

  • Tampermonkey API（GM_xmlhttpRequest、GM_setValue、GM_getValue、GM_registerMenuCommand）
