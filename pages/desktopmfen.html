马画马桌宠

真冬 + 绘名桌宠，包含番茄钟、点击互动、随机对话功能，使用 Godot 开发。

点击下方按钮前往 itch.io 下载对应系统版本。

前往下载（itch.io）

提示：请在 itch.io 页面中选择 Windows 或 Mac 对应版本下载。

下载前必读

Windows 用户：直接点开 exe 文件即可运行。

MacOS 用户：

以下是安装指引：

  1. 把 DMG 里的 .app 文件拖拽到“桌面”或者“应用程序”文件夹里。不要直接在 DMG 里面双击打开。
  2. 打开终端（Terminal）（按 Command+空格，搜 Terminal）。
  3. 复制并粘贴这行命令但是不要回车（注意 cr 后面有一个空格）：
    xattr -cr
  4. 不要按回车。把刚刚拖到应用程序/桌面上的 DesktopPet.app 图标拖进终端窗口。
  5. 然后终端会显示：xattr -cr /Users/yourname/Desktop/DesktopPet.app
  6. 再回车。这样之后应该就可以正常打开了。

功能简介

  • 番茄钟计时
  • 点击互动反馈
  • 随机对话文本
